WePROXA **3.3.0** puts certificate setup, scripting, and workspace switching right where you need them, and makes the request list faster to navigate with nested menus, tool grouping, and app icons.

## New Features

- **Script import & export** - Share and back up your scripting rules by exporting them to a file and importing them into any workspace.
- **CA certificate lifecycle** - Regenerate, export, and manage the local CA certificate directly from Settings.
- **Certificate trust guidance** - New trust indicators and a guided setup flow show whether the CA is trusted and walk you through fixing it.
- **Native workspace switcher** - Switch between workspaces straight from the macOS menu bar and system tray.
- **Requests grouped by tool** - The sources sidebar now groups modified requests by the tool that changed them, so you can see what each rule touched.
- **Nested context menus** - Right-click menus now support nested submenus for faster navigation of request and source actions.
- **Filter from the context menu** - Filter the request list by a request's host or client with a single click from its context menu.

## Fixes & Improvements

- **App icons in the client column** - The request list now shows each client app's icon alongside its name for quicker scanning.
- **macOS window vibrancy** - App windows adopt native macOS vibrancy for a more integrated look that follows the system theme.
- **Clear displayed requests only** - Clearing the request list now removes only the requests currently displayed, respecting your active filters.

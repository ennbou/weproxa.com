We're excited to introduce **WePROXA** — a powerful HTTP/HTTPS proxy debugger built from the ground up for macOS.

## Why We Built WePROXA

Debugging network traffic is a fundamental part of modern development. Whether you're building web apps, mobile apps, or APIs, understanding what's happening at the network level is crucial. We wanted a tool that's:

- **Native and fast** — built with Tauri and Rust for macOS performance
- **Modern UI** — clean React interface designed for developer workflows
- **Full-featured** — breakpoints, map local, request replay, and more

## Key Features

- **Real-time traffic capture** with support for HTTP and HTTPS
- **Breakpoints** to intercept and modify requests mid-flight
- **Map Local** to serve local files instead of remote resources
- **Request replay** to resend and modify captured requests
- **Advanced filtering** with a powerful query builder
- **MCP integration** for AI-powered debugging workflows

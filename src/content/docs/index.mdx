## Install from Terminal on macOS

```sh
curl -fsSL https://weproxa.com/i | bash
```

On Windows, install WePROXA from the [Microsoft Store](https://apps.microsoft.com/detail/9p9npx1zvrjs). See [Installation Windows](/guide/getting-started/installation-windows/).

## Why WePROXA?

WePROXA is a **native macOS and Windows proxy debugger** built with Tauri, React, and Rust — designed for speed, clarity, and developer experience. Whether you're debugging API calls, testing mobile apps, or building integrations, WePROXA gives you full visibility into your HTTP traffic.

Get up and running with Weproxa in just a few steps.

<Steps>

1. **Launch Weproxa** from your Applications folder.

   ![Weproxa startup screen](@assets/guide/getting-started/launch_weproxa.png)

2. **Start the proxy** by clicking the play button in the toolbar or pressing `⌘ + P`.

   ![Weproxa with requests](@assets/guide/getting-started/start_with_request.png)

3. **Enable the system proxy** — Weproxa can automatically configure your Mac's system proxy settings. Click the network icon in the toolbar to toggle it on.

4. **(Optional) Auto-start on launch** — in **Settings** you can enable **Auto-start proxy** and **Auto-start LAN access** so Weproxa is ready to capture traffic as soon as you open it.

5. **Install the CA certificate** — to inspect HTTPS traffic, go to **Settings** → **Certificates** and click **Install to macOS Keychain**. This is a one-time setup. See [Certificate Trust](/guide/guides/certificate-trust/) for details.

6. **Enable SSL for a host** — click the **lock icon** in the toolbar and add the hosts you want to inspect (e.g., `api.example.com` or `*.example.com`). Alternatively, right-click any request and select **Enable SSL**. See [SSL Interception](/guide/guides/ssl-interception/) for details.

7. **Browse the web** — open your browser or app and make some requests. They'll appear in the request list in real time.

8. **Inspect a request** — click on any request in the list to see its full details: headers, body, timing, and more.

</Steps>

WePROXA 3.0.0 is the first release with Windows support. You can install the Windows build from the [Microsoft Store](https://apps.microsoft.com/detail/9p9npx1zvrjs) or with WinGet from Command Prompt.

## System Requirements

- **Windows 10** or **Windows 11**
- 64-bit Windows
- Microsoft Store access

## Install from Microsoft Store

<Steps>

1. Open [WePROXA in the Microsoft Store](https://apps.microsoft.com/detail/9p9npx1zvrjs), or open the **Microsoft Store** app on Windows.

2. Search for **WePROXA**.

3. Select **Get** or **Install**.

4. Launch **WePROXA** from the Start menu after installation completes.

5. Open **Settings** -> **Certificates** and choose **Learn More** if you plan to inspect HTTPS traffic. See [Windows HTTPS Certificate Setup](/guide/guides/windows-https-certificate-setup/) for details about the local CA certificate and certificate trust.

</Steps>

The Microsoft Store handles Windows app updates automatically unless you have disabled Store updates.

:::note
WePROXA 3.1.0 fixes Microsoft Store package restrictions that could prevent the app from updating the current user's proxy settings or writing its generated certificate files. Update through the Microsoft Store or WinGet if the system proxy does not change or **Certificate Path** is empty.
:::

## Install from Command Prompt

Open **Command Prompt** and run:

```cmd
winget install weproxa
```

WinGet downloads and installs WePROXA from the Microsoft Store.

## Setup Notes

- Start the proxy from the toolbar, then enable the system proxy with the network button.
- WePROXA configures the Windows system proxy for the current user and restores the previous values when the proxy stops or the app exits normally.
- If the network button does not update Windows proxy settings, confirm that WePROXA is version 3.1.0 or later, quit the app completely, and open it again.
- Some command-line tools need `HTTP_PROXY` and `HTTPS_PROXY` environment variables even when the Windows system proxy is enabled. See [Quick Start](/guide/getting-started/quick-start/#terminal-proxy-setup) for shell examples.
- Firefox and some developer tools may use their own proxy or certificate store. Configure them to use system settings before testing HTTPS interception.

## Uninstall

To uninstall WePROXA on Windows:

1. Quit WePROXA if it is running.
2. Open **Settings** → **Apps** → **Installed apps**.
3. Find **WePROXA**, open the overflow menu, and choose **Uninstall**.
4. If you previously trusted the WePROXA Root CA, remove it from the current user's trusted root store. See [Windows HTTPS Certificate Setup](/guide/guides/windows-https-certificate-setup/#removing-the-certificate-later).

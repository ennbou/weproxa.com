WePROXA 3.0.0 and later supports both macOS and Windows. This page covers the macOS build. For Windows, see [Installation Windows](/guide/getting-started/installation-windows/).

## System Requirements

- **macOS 11.0** (Big Sur) or later
- Apple Silicon (M1/M2/M3) or Intel Mac

## Download

Download the latest macOS version of WePROXA:

```sh
curl -fsSL https://weproxa.com/i | bash
```

## Install

<Steps>

1. **Open the DMG file** you downloaded.

2. **Drag WePROXA** into your Applications folder.

3. **Launch WePROXA** from your Applications folder or Spotlight.

4. **Trust the certificate** — on first launch, WePROXA will ask to install a root CA certificate. This is required for HTTPS interception. See [Certificate Trust](/guide/guides/certificate-trust/) for details.

</Steps>

## Uninstall

To uninstall WePROXA:

1. Quit WePROXA if it's running.
2. Drag WePROXA from your Applications folder to the Trash.
3. Optionally, remove the CA certificate from your Keychain (search for "WePROXA" in Keychain Access).
